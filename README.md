# Website Ulang Tahun Salisa (Miel) 🎂

Website interaktif dan meriah yang dibuat khusus untuk ulang tahun ke-16 Salisa (Miel) pada tanggal 22 November.

## Cara Deploy ke Vercel via GitHub:

1. **Upload ke GitHub:**
   - Ekstrak file ZIP ini di komputer/HP kamu.
   - Buka GitHub (buat akun jika belum punya).
   - Buat Repository baru, beri nama bebas (contoh: `sweet16-miel`).
   - Upload ketiga file (`index.html`, `style.css`, `script.js`) ke dalam repository tersebut lalu klik "Commit changes".

2. **Deploy di Vercel:**
   - Buka [Vercel](https://vercel.com/) dan login menggunakan akun GitHub kamu.
   - Klik **"Add New"** > **"Project"**.
   - Import repository `sweet16-miel` yang baru saja kamu buat.
   - Biarkan semua pengaturan default, lalu klik **"Deploy"**.
   - Tunggu beberapa detik, Vercel akan memberikan link website (URL) yang bisa kamu bagikan ke Salisa!

Semoga perayaannya berjalan lancar! 🎉
